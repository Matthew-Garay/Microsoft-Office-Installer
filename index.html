How to Install

1. Open PowerShell as Administrator Search for PowerShell in the Start menu, right-click it, and select "Run as administrator".
2. Execution Policy (First time only) If it's your first time running scripts, run this command first: Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy Bypass
3. Copy & Run the Command Choose above between GUI or CLI, click Copy, paste it into PowerShell and press Enter.

Technology, Version & Purpose

Technology & Version Powered by Microsoft Office Deployment Tool (ODT) Version 18227. Uses native XML configuration streams.
Why it was used To allow clean, direct downloads and installations straight from official Microsoft servers without requiring third-party ISO files, bloatware, or external tools.
