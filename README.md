# Microsoft Office Installer

## Professional Installer for Microsoft Office

A comprehensive set of PowerShell scripts to automate Microsoft Office installation on Windows using the official Microsoft Office Deployment Tool (ODT).

## Features
- GUI and CLI installation modes
- Supported: Office LTSC 2024/2021, Professional Plus 2019/2016/2013
- 64-bit and 32-bit architectures
- 10 languages available
- Step-by-step guided installation

## Quick Start
`powershell
irm https://raw.githubusercontent.com/Matthew-Garay/Microsoft-Office-Installer/main/instalar-gui.ps1 | iex
`
